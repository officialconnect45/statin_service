# Statin

Product studio site for Statin: websites, SaaS, and ecommerce for startup founders.

## Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit

- Copy, services, and the public email live in `src/lib/site.ts`.
- Contact briefs are appended to `data/inquiries.jsonl` on this machine. That folder is gitignored.
- Set `site.email` and `site.url` before you publish.
